PIXEL TREK 0.3.1 - TREK EDITION
Five cities. One curious mouse.

RUN / UPDATE
Extract this ZIP and open PixelTrek.exe. Quit the older copy first.
Your existing lifetime/day/hour counts and motion peaks carry over.
No installer or browser runtime. Requires .NET Framework 4.8 on Windows.
The unsigned app can trigger Windows/workplace security checks.

YOUR LITTLE GETAWAY
Choose New York (default), Sydney, London, Moscow or Paris in the dropdown.
Every city has six labelled stops and a playful 20 m street checkpoint:
  New York: Broadway
  Sydney: Alfred Street
  London: Whitehall
  Moscow: Nikolskaya Street
  Paris: Rue de Rivoli

The winding trail maps your lifetime cursor-distance equivalent onto
approximate straight-line landmark legs. It is an illustration, not
street navigation or actual walking distance. The street stop is a
playful 20 m threshold near the starting landmark. Each finished city
trail starts another virtual lap. Switching cities reuses your lifetime
total and never resets counts. Your selected city is saved.

THE HOME SCREEN
Next badge has its own card and progress bar. The same ten thresholds
remain: 100 m, 500 m, 1, 2, 5, 8, 10, 15, 50 and 100 km equivalents.
City badge comparisons change with the dropdown selection.
Acceleration is in the middle, with live speed alongside it. Below are
Today / Last hour / Lifetime and the cursor, key-tap and click counts.
The mouse explores while input is active and rests when idle.

Normal size: 575 x 472 logical pixels; compact: 575 x 82.
Drag the header to move. Use minus to collapse, arrow to hide to tray,
three dots or right-click for ordinary controls. Double-click the tray
icon to restore. History includes expanded key/click achievements and
motion peaks. Optional Windows startup is a per-user setting.

SCREEN EQUIVALENTS
Default: 96 PPI. Pixels remain the canonical count.
  km = pixels x 0.0254 / PPI / 1000
  m/s = pixels per second x 0.0254 / PPI
  m/s^2 = pixels per second squared x 0.0254 / PPI
One million pixels is about 0.265 km at 96 PPI. This is screen cursor
travel, not physical mouse or trackpad travel. Acceleration includes
braking and direction changes and is smoothed. Screen scale applies
across all monitors and saved history, and does not change pixels.

LOCAL COUNTS ONLY
This edition has no Flow, Loops, Signals, Context or Privacy tabs and
no analytics engine. It never reads app names or calendar data, including
when an older save had those options enabled. No typed text, ordered key
sequences, screenshots or exact cursor trails are saved. No networking.
Held-key repeats are ignored; physical presses include modifier keys.
Injected mouse events are excluded. Cursor jumps/locked-pointer games,
secure desktops and elevated apps can affect coverage or interpretation.

SAVE / EXPORT
Saved totals: %LOCALAPPDATA%\PixelTrek\counters.json
Checkpoints every 10 seconds, with a previous-save .bak recovery file.
366 active dates of daily history; lifetime totals retained separately.
The last hour is a sliding 60-minute window, not the last clock hour.
Quit & save before updating. After a sudden interruption, activity since
the latest successful checkpoint may be lost.

Old v0.3.0 insights.json files are never opened or changed by this build.
Remove them manually after quitting if you no longer want that history.
Explicit recap PNG, CSV history and counters backup exports remain.
